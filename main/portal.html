Qoder Passport

让助手连接你的世界

在这里配置 Wi-Fi 与 Qoder Cloud Agents 的个人访问令牌。设置只保存在设备上。

这个热点用于配置，不提供互联网。请先获取 PAT，再连接设备热点；如果链接打不开，切换手机移动数据或使用另一台设备查看。

01 · 连接 Wi-Fi

设备就绪后将自动扫描附近网络。

名称最多 32 字节；页面 maxlength 限制不是字节校验，最终以设备校验为准。

同一网络密码留空可保持原密码；新网络需填密码。

不支持需网页登录的酒店/校园网络或企业 802.1X 认证。请使用可直接联网的家庭路由器或手机热点。

02 · 授权 Qoder Cloud Agents

如何获取 PAT →

登录 qoder.com → 设置 → 个人访问令牌 → 创建令牌。选择所需权限与有效期；令牌完整内容只显示一次。

首次配置必须填写 PAT。设备会验证其访问权限，不会把令牌回显到网页。

正在连接设备配置服务…
请保持连接设备热点，直到提示配置成功。
热点连接使用 WPA2；设备 NVS 目前未启用存储加密。

恢复出厂设置：在设备的模板选择页或热点配置页长按 OK → 设备设置 → 恢复出厂设置。会删除 Wi-Fi、PAT 和音量设置，不删除云端会话；需要设备上二次确认。
