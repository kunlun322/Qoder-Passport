# Qoder-Passport 使用指南

这是面向使用者的说明：从拆开 FoloToy AI Passport、刷入 Qoder-Passport，到接入你的
网络和 Qoder 账号，再到日常使用。板卡内部细节与源码构建见
[文档索引](/docs/README.zh_CN.md)。

## 你需要准备

| 物品 | 说明 |
| --- | --- |
| FoloToy AI Passport 设备 | ESP32-C3，8 MB Flash，240 × 320 屏 |
| USB Type-C 数据线 | 必须是**能传数据**的线，5 V。用于烧录与串口日志 |
| 一台装有 Python 与 `esptool` 的电脑 | 任意操作系统；烧录只需 `pip install esptool` |
| 2.4 GHz Wi-Fi 网络 | ESP32-C3 射频不支持 5 GHz |
| 带 Personal Access Token 的 Qoder 账号 | 在 Qoder 账号设置中创建 |
| 用于配网的手机或笔记本 | 连上设备热点后打开网页 |

烧录预编译发布版**不需要** ESP-IDF；只有从源码构建才需要。

## 电源与按键

- **电源键**（独立硬件按键）：长按约 0.5 秒开机，约 2 秒关机。
- **▲ / ▼ / OK**：正面三颗功能键。短按判定 180 ms，长按判定 500 ms。
- 屏幕自动熄灭后，按任意功能键即可唤醒。
- 屏幕不支持触摸，所有操作都通过三颗按键完成。

各页面的按键含义见[按键说明](/README.zh_CN.md#按键说明)。

## 烧录固件

先确认串口，不要猜：Windows 上其它 COM 口可能属于无关硬件。

```bash
# 列出串口（Linux/macOS：ls /dev/ttyACM* /dev/ttyUSB*）
python -m serial.tools.list_ports -v
```

AI Passport 通过原生 USB Serial/JTAG 枚举，USB `VID:PID = 303A:1001`。

然后把合并镜像写入偏移 `0x0`：

```bash
python -m esptool --chip esp32c3 -p <端口> -b 460800 \
  write_flash 0x0 Qoder-Passport-v0.1.0-esp32c3-full.bin
```

烧录前先校验下载文件：

```bash
sha256sum Qoder-Passport-v0.1.0-esp32c3-full.bin
```

哈希必须与[发布说明](/docs/development/release/v0.1.0.zh_CN.md)中公布的值一致。

> [!WARNING]
> 合并镜像覆盖 bootloader、分区表与应用，并填充它们之间的空隙。从 `0x0` 整片写入会
> **清空 NVS 区域**，已保存的 Wi-Fi 凭据、PAT 与音量都会丢失，设备将重新进入配网模式。
> 首次安装时这是预期行为。
>
> 若要升级并保留配置，只按各自偏移写入 bootloader 与应用，不要碰 `0x8000`（分区表）
> 与 `0x9000`（NVS）。仅当新分区表与设备上现有的逐字节一致时才安全；发布说明会给出
> 分区表哈希供比对。详见
> [固件布局与烧录策略](/docs/development/engineering/firmware-layout.zh_CN.md)。
>
> 绝不要为了修一个普通错误而整片擦除 Flash。

## 首次使用：配置 Wi-Fi 与 PAT

Qoder-Passport 换网络时不需要改源码，也不需要重新烧录——它自带配置门户。

1. 开机。
2. 若没有可用的 Wi-Fi 凭据或没有 PAT，屏幕会切到配网页，显示：
   - 二维码；
   - 热点名称（SSID）；
   - 本次会话随机生成的临时 WPA2 密码；
   - 门户地址 `192.168.4.1`。
3. 用手机或笔记本连上该热点，密码就是屏幕上显示的那个。热点是 WPA2 加密，不是开放网络。
4. 打开 `http://192.168.4.1`。若系统弹出强制门户提示，选择继续访问。设备在网关地址上
   跑了 DNS 服务，任意域名都会解析到门户。
5. 页面会列出附近网络及信号强度，选中你的 Wi-Fi。若是隐藏网络，用手动输入项填写完全
   一致的 SSID。
6. 填写 Wi-Fi 密码。若只是更换 PAT，页面可以沿用已有的 Wi-Fi 密码。
7. 粘贴你的 Qoder Personal Access Token。
8. 点击保存。页面进入进行中状态并轮询设备。

设备侧接下来会发生：

- 以 STA 身份连接你的网络。若家用路由器拒绝首次关联（设备刚从 AP 切到 STA 模式时很
  常见），会按 1.2 s、2.4 s、3.0 s、3.0 s、3.0 s 的退避重试。
- 用你的 PAT 调 QCA 接口确认令牌确实可用。**PAT 校验通过后才落盘**，因此无效令牌不会
  把设备留在半配置状态。
- 成功后把 Wi-Fi 凭据与 PAT 存入 NVS，屏幕显示完成，约 3 秒后重启进入正常模式。
- 失败时屏幕与网页都会指出卡在哪一步：Wi-Fi、PAT、服务还是保存。每个失败页都提供重试，
  长按 OK 可进入设备设置。

若页面提示"请连接热点设备"，说明浏览器是通过别的网卡访问到设备的。重新连上热点、
关掉手机移动数据，再刷新页面。

## 选择 Agent 与身份

配网完成后设备会重启并自动联网。之后每次开机它会复用上次见到接入点的信道，
关联速度明显更快。

1. **第 1 步——选择 Agent 模板。** 设备通过 HTTPS 拉取你的 QCA 模板列表。▲/▼ 移动
   （双击移动 2 项，长按翻一页 5 项），OK 确认，右上角显示 n/N 计数。
2. **第 2 步——选择用户身份。** 操作相同。OK 开始对话，长按 OK 返回第 1 步。

任一列表拉取失败时，出错页会说明原因并提供 `OK` 重试；在模板页长按 OK 可进入设备设置。

## 开始对话

会话建立后，语音页标题是模板名，副标题是身份名，下方是状态词与转写行。

屏幕上的状态词依次为：连接中、聆听中、思考中、回答中、已暂停、已结束、出错了。

- 直接说话即可。会话是全双工的，Agent 说话时你可以插话打断，它会停下来听你说。
- **▲ / ▼** 以 10 为步进调音量，会有浮层提示当前音量。
- **OK 单击**暂停 / 继续。
- **OK 长按**结束对话，返回身份列表。
- 喇叭音量足以免提使用；麦克风链路带设备端增益与削波控制，说话大声也不会让上行失真。

## 设备设置

在模板页、配网页或 Wi-Fi/PAT 失败页**长按 OK** 进入设置，菜单项如下：

| 菜单项 | 作用 |
| --- | --- |
| 取消配置并重启（仅配网页） | 退出热点，不保存任何内容 |
| 刷新 Agent 列表（正常页面） | 重新拉取模板与身份 |
| 重新配置 Wi-Fi / PAT | 重启进入配网门户 |
| 恢复出厂设置 | 二次确认，见下 |
| 返回上一页 | 回到上一屏 |

光标默认停在**返回上一页**，所以误触长按不会有任何效果，除非你主动移动选择。

### 恢复出厂设置

选择恢复出厂后会出现确认页，明确列出将删除的内容：Wi-Fi 凭据、PAT 与音量设置；
也明确列出**不会**删除的内容：云端会话。

- 确认页默认选中**取消**。
- 即便手动选中清除项，仍需**长按** OK 才会真正执行。
- 设备会停掉 Wi-Fi、删除已存值，然后重启进入配网模式。
- 若删除中途失败，设备会保留重置意图，告知未进入正常联网并提供重试，绝不会把失败的
  重置说成成功。

恢复出厂不整片擦除 Flash，也不触碰 PHY 校准分区中重置所不需要的部分。

## 串口控制台

控制台在原生 USB Serial/JTAG 上，**波特率 115200**——不是某些其它 ESP32 板子用的
2000000，也不是 UART0。

```bash
python -m esptool --chip esp32c3 -p <端口> ...   # 烧录
idf.py -p <端口> monitor                          # 若已安装 ESP-IDF
```

打开串口是否会让设备复位，取决于工具与 DTR/RTS 电平。日志绝不会打印你的 SSID、
Wi-Fi 密码或 PAT，凭据相关代码只记录长度与错误码，例如：

```
I (1048) qca_pat: 已读取 PAT（内容不记录）
I (1049) main: 配置已就绪，剩余堆 98972
```

## 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| 屏幕全黑 | 先充电；确认电源键按住了 0.5 秒。显示依赖 GPIO21 的背光 |
| 门户页提示"请连接热点设备" | 手机/电脑经其它网卡访问到了设备。重连热点、关移动数据、刷新 |
| 门户页完全打不开 | 确认已连上设备 SSID，并从它的 DHCP 拿到了 `192.168.4.x` 地址 |
| 页面能打开但保存无反应 | 门户会拒绝缺少一次性 CSRF 令牌的写请求，刷新页面重新取令牌 |
| 配网后 Wi-Fi 连不上 | 路由器可能拒绝了首次关联，或密码错误。在失败页重试；确认是 2.4 GHz 频段 |
| 重启后总是回到配网页 | 要么开机时网络不可见（会重试约 21 秒再回退到热点），要么 PAT 校验没过。重跑配网 |
| PAT 被拒 | 令牌错误、过期或权限不足，到 Qoder 账号里重新创建 |
| 语音连上了但没声音 | 若 codec 没起来，出错页会报音频初始化失败。重启；仍复现就抓串口日志 |
| 信号弱时对话中断 | 会话会报告断线并提供重试，靠近接入点 |
| 部分中文显示成方框 | 提交进仓库的字体缺该字形，见[中文字体指南](/docs/development/engineering/lvgl-chinese-fonts.zh_CN.md) |

反馈问题时请附上固件版本与发布说明中的 ELF SHA-256，这样才能用正确的符号解析崩溃
日志。分享日志前先去掉 Wi-Fi 凭据、令牌、设备二维码内容与个人数据。
